# 小学语文课件 / 教案生成器

把一节课文名变成三份可上课的成品：`.pptx` 课件、HTML 互动课件、`.docx` 教案。
用小学语文教学专业知识生成结构化内容，脚本负责渲染——
全程不依赖 OpenAI API Key、不需要 LaTeX / pandoc。

## 何时使用此 skill

- 用户给课文名 + 年级（+ 课型），要"做课件""生成教案""做个 PPT"。
- 用户提到小学语文某课（如"二年级坐井观天""一年级静夜思"）并想要教学材料。
- 用户想批量产出识字 / 古诗词 / 精读 / 习作课件。

只在用户**明确要生成课件或教案**时调用。仅讨论语文教学、不改课、写逐字稿等不在范围内。

## 资源定位

脚本与资源相对 SKILL.md 所在目录定位：

```bash
# SKILL_DIR 为 yuwen/ 目录（本文件所在目录）
python "scripts/render_all.py" <json文件> --out <输出目录>
```

- 参考文档（生成 JSON 时必读）：`references/schema.md`、`references/lesson-types.md`、`references/stages.md`、`references/curriculum.md`。
- 完整示例：`references/examples/zuojing-guantian.json`（精读）、`references/examples/jingyesi.json`（古诗词）。

## 工作流（五步）

### 1. 解析输入

收集三要素，缺则用 AskUserQuestion 主动补齐：

| 要素 | 取值 | 默认 |
|------|------|------|
| 课文名 | 如"坐井观天" | 无默认，必问 |
| 年级 | 1-6 | 无默认，必问 |
| 课型 | 精读 / 识字写字 / 古诗词 / 口语交际习作 | 只给课文名时默认"精读"并确认 |

课文名与年级是硬性需求；只给课文名时按"精读"处理但需向用户确认。

### 2. 定档

- 年级 → 学段：1-2 低段 / 3-4 中段 / 5-6 高段。
- 读 `references/stages.md` 取该学段约束（页数范围、识字量、写字量、朗读/习作字数）。
- 读 `references/lesson-types.md` 取该课型的必选栏目序列（精读分两课时，栏目结构不同）。

### 3. 生成 JSON

按 `references/schema.md` 契约产出 `{ meta, slides, lessonPlan, handout }`。**生成后逐项自检**：

- `meta.lessonType` 在枚举 `{精读, 识字写字, 古诗词, 口语交际习作}` 内。
- 每个 `objectives[].competency` 是四大素养之一：**文化自信 / 语言运用 / 思维能力 / 审美创造**（强制对齐新课标）。
- 每页 `elements[].type` 在元素类型全集内（见 schema.md）。
- 精读课 `slides` 按 `period:1` / `period:2` 分两课时。

内容要贴合真实教学：识字卡带拼音/部首/笔画/组词/造句；精读逐段品析；古诗带节奏注音；习作带星级评价量表。**参照示例 JSON 的密度与结构**，不要偷工减料。

### 4. 渲染

把 JSON 落盘后调总入口（JSON 写文件用 Write，渲染用 python 命令匹配 `Bash(python:*)` 权限）：

```bash
python "scripts/render_all.py" <json文件> --out ~/Desktop/语文课件/<课文名>-<课型>/
```

`render_all.py` 会：校验 schema → 调三个渲染器 → 按课时分文件输出 → 打印每个文件路径。

依赖首次缺失时脚本会给出中文安装提示；如需补装：`pip install -r requirements.txt`。

### 5. 报告

列出三个文件完整路径 + 课时建议（按 `meta.periods`），并提示老师可在 HTML 课件里用浏览器全屏上课、pptx 可二次编辑、docx 可直接交学校存档。

## 课型与栏目序列（速查）

详见 `references/lesson-types.md`，此处为骨架：

| 课型 | 课时 | 栏目序列（kind） |
|------|------|------------------|
| 精读 | 1 | 封面→目录→学习目标→情境导入→初读感知(注音课文)→会认字(生字卡)→会写字(田字格+笔顺)→词语理解→再读梳理→小结→基础作业 |
| 精读 | 2 | 复习导入→精读品析(逐段5-8页)→合作探究→朗读指导→写法总结→拓展延伸→板书设计→课堂练习→分层作业→结束页 |
| 识字写字 | 1-2 | 激趣导入→认读字音→字形分析(字理)→书写指导(田字格)→组词造句→巩固游戏→作业 |
| 古诗词 | 1-2 | 诗人背景→初读节奏(注音)→诗意解析→悟情意象→背诵指导(填空背)→拓展对比→板书 |
| 口语交际/习作 | 1 | 情境导入→目标明确→方法支架→范文赏析→小组活动(角色扮演)→星级评价→当堂练习→成果展示 |

## 新课标内置

- 四大核心素养：文化自信、语言运用、思维能力、审美创造（见 `references/curriculum.md`）。
- 每个教学目标**必须标注** `competency`（四素养之一）；`dimension`（传统三维目标）可选，docx 可按学校习惯切换。
- 每个栏目挂素养条目：朗读指导→语言运用、情感体悟→文化自信、合作探究→思维能力、板书审美→审美创造。

## 约束

- **零外部 LLM**：不 import openai，不发任何网络请求做内容生成。
- **零 LaTeX**：不依赖 pdflatex / pandoc；拼音田字格用 Pillow 预渲染 PNG。
- 输出目录默认桌面 `~/Desktop/语文课件/<课文名>-<课型>/`，可 `--out` 覆盖。
- 退出码：0 成功 / 1 异常 / 2 前置缺失（schema 校验失败或依赖缺失）。
